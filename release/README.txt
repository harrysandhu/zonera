Zonera demo
===========

Open zonera-demo.html in Chrome, Edge, Safari or Firefox (double-click it).
No server or internet needed. Fonts load from Google Fonts when online;
offline it falls back to your system font.

Movie mode (for filming)
  Click "Movie mode" in the dark bar at the bottom. Pick:
    A Friday at Alder Lake   the full story, about 7 minutes, 11 chapters:
                             a customer rents online, the morning on the
                             dashboard, payments, a walk-in, three move-ins,
                             a vendor gate code, collections, the AI call
                             center, a call that needs a manager, every screen
                             updating, and the owner report.
    Any chapter              start the story from that scene (for retakes).
    Agent chains             several agent flows played in one chat.
  While it plays: Space pauses, Right arrow skips a scene, Esc stops,
  "c" hides captions. The speed button cycles 1x, 1.5x, 2x.
  Playing from the start reloads the page first so every take is clean.

Where to go (use the dark bar at the bottom of the screen):
  Storefront   customer site: size finder, 3D facility, checkout, gate route
  Operator     dashboard: overview, digital twin, tenants, payments, more.
               The "Ask Zonera" buttons on each page hand the task to the agent.
  Agent        Zonera agent. Its home screen has starters, "Watch it work"
               chains and a library of 40+ requests that all run end to end.
               Every reply ends with next-step chips, so one chat can chain
               many flows. Some to type:
                 Matthew came in and paid $240 cash
                 New customer wants a 10x10 today, Jordan Lee
                 Move these three reservations in today: Owen Murphy, Hana Sato, Imani Mensah
                 Move Sofia Reyes from her 5x10 to a 10x10
                 Ben Carter is moving out Friday
                 Make a gate code for the HVAC tech, 1-5pm today, Building D only
                 Who came in after 10pm last night?
                 Who's more than 15 days late?
                 Start the lien process for Dana Whitfield
                 Fix last night's autopay failures
                 Refund Grace's duplicate charge
                 Run a $1 first month on 10x20s until we hit 90%
                 Raise rates 6% for tenants here over a year
                 The door on C-120 is jammed
                 Generate the September owner report vs last year
                 I don't want to do the walkthroughs or the auction prep today
                 Call Leila Haddad and finish her reservation
                 Take over the call
  Calls        AI call center panel (slides in from the right)
  Brand        brand guide

Press "." to hide the bottom demo bar for clean recordings.

Run from source instead: npm install, then npm run dev (http://127.0.0.1:5173).
